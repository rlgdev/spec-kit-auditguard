# Feature Specification: Refunds

### User Story 1 - Refund a cancelled order (Priority: P1)

A customer who cancels an order gets the payment back.

## Requirements

- **FR-001**: System MUST refund the full order total when an order is cancelled.
- **FR-002**: System MUST record every refund with its payment reference.
- **FR-003**: System MUST support partial refunds of single order lines.
